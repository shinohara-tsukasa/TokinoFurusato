（１）動作環境
----------------------------------------------------------

・Windows98/Me/NT4.0/2000/XP/Vista/7が快適に動作する環境
・JavaScriptが動作するブラウザ、IE5.5以降
・動作確認は、Windows+IE6,IE7,IE8で行なっています。
・効果音・ムービー再生にはFlash Player5以降が必要です。
・JavaScriptをOffにして使っている方は、必ずOnにして下さい。
・640x480、64K色以上の表示能力
(640x480表示の場合は、フルスクリーンモードをご使用ください）

----------------------------------------------------------
（２）インストール／アンインストール
----------------------------------------------------------

ダウンロードしたファイルを実行するとインストールプログラム
が起動しますので、インストールするフォルダを指定してください。
あとは画面の指示に従ってインストールを完了させてください。
アンインストールは、コントロールパネルから行なうことができます。

----------------------------------------------------------
（３）ゲームの起動
----------------------------------------------------------

スタートメニューから「時の故郷完全版3.10」を選び、
時の故郷完全版3.10の起動
を選んでください。

----------------------------------------------------------
（４）ゲームの進行
----------------------------------------------------------

このゲームは、画面上に表示されるメッセージを読み、選択肢を
選びながら進行するノベルタイプのアドベンチャーゲームです。
画面上のメッセージを進めるには、画面の任意の場所で左クリッ
クします。選択肢が画面に出てきた場合は、選択肢の青い文字を
クリックすると物語が進行します。

画面上の画像をよく見たい場合は、マウスカーソルをウインドゥ
外へ移動させてください。メッセージウインドゥが消去されます。
再びマウスカーソルをウインドゥ内に戻すと、メッセージが再度
表示されます。
（フルスクリーン版をプレイしている時は、画面最下部にマウス
カーソルを移動させるとメッセージが消えます）

また、マウスカーソルをウインドゥ上部へ持っていくと、メニュ
ーが表示されます。スキップ・セーブ・ロード・環境設定・ヘル
プ表示・タイトルへ戻る・テキスト読み返しといった７つの機能
を使うことができます。
詳しくは、タイトル画面から「操作説明」をクリックしてご覧下さい。
